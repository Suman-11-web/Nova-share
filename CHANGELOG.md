# Changelog

All notable changes to Nova Share will be documented in this file.

## [1.0.0] - 2026-08-01

### Added
- Initial public release of Nova Share.
- Cross-platform Web Share server (Phone ↔ PC/Mac/Linux/Browser).
- Ultra-fast local P2P socket engine with live speed meter and ETA.
- QR Code pairing and PIN security model.
- Room database transfer logs and storage analytics.
- Jetpack Compose Material 3 UI with Light, Dark, Dynamic, and AMOLED pitch black themes.
- GitHub Actions CI/CD workflows for building debug/release APKs and running tests.
