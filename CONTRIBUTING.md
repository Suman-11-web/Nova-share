# Contributing to Nova Share

Thank you for your interest in contributing to Nova Share!

## How to Contribute
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add amazing feature'`).
4. Ensure all unit tests pass locally (`gradle testDebugUnitTest`).
5. Push to your branch and open a Pull Request.

## Code Style
Please adhere to standard Kotlin guidelines and Compose best practices.
